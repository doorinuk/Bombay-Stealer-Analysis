Execution flow

Behavior inferred from the supplied command text, not from running it.

Static analysis
01

Conceal the PowerShell session

-WindowStyle Hidden, -NonInteractive, and -ExecutionPolicy Bypass reduce visible prompts and bypass the usual execution-policy gate. These flags are suspicious in combination, but not malicious in isolation.

02

Prepare network compatibility

Attempts to select supported TLS versions and temporarily accept any server certificate. The certificate-validation override weakens HTTPS identity checks.

03

Download and unpack an archive

Retrieves readme.zip from a GitHub raw-content URL and extracts it under the current user's roaming application data in a directory named Microsoft\Edge.

04

Establish logon persistence

Writes a SystemSettingsBroker value under HKCU\Software\Microsoft\Windows\CurrentVersion\Run. It also interacts with the Explorer StartupApproved\Run key.

05

Launch a script wrapper

Writes a VBScript file that checks for a matching process and starts a command line using a configured pool URL and worker argument. The script later invokes the VBScript through wscript.exe.

06

Reduce installation artifacts

Removes selected README/archive and batch files during the installation path. Cleanup can complicate casual inspection, though it does not prove that all traces are erased.

Defensive response

Use these steps if the command may have been executed on a real endpoint.

Immediate containment

  • Isolate the affected endpoint from the network if compromise is suspected.
  • Preserve the original command, timestamps, PowerShell logs, and any downloaded archive for analysis.
  • Run Microsoft Defender Offline and a full scan, following organizational incident-response policy.
  • If this is an enterprise host, notify the security team before deleting artifacts.

Hunt and verify

  • Review the user's Run and StartupApproved registry keys for the named value.
  • Inspect the referenced application-data directory and VBScript contents.
  • Correlate process creation for powershell.exe, wscript.exe, and any child processes.
  • Review outbound connections to the listed pool endpoint and the download domain.
  • Search endpoint telemetry for the exact IOC strings and nearby execution events.
Evidence handling: Do not execute the payload on a normal workstation. If you need dynamic analysis, use a disposable, isolated virtual machine with controlled networking and snapshots. Do not rely on deleting the Run value alone as proof of remediation.

Assessment and confidence

Current conclusion

High confidence that the command implements a hidden downloader/installer with logon persistence. Moderate confidence that the intended workload is cryptocurrency mining due to the Stratum endpoint and XMRig-like worker string. Low confidence regarding any infostealer capability until the ZIP and its contents are examined.
